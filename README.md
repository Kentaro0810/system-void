# SYSTEM//VOID 安全な短編ホラー v1.0

ブラウザ内だけで動く架空のシステムホラーです。端末情報の取得、外部通信、保存、通知、ダウンロード、カメラ・マイク利用はありません。

## GitHub Pagesで公開
1. GitHubで新しい公開リポジトリを作成します。
2. このフォルダ内の `index.html` をリポジトリ直下へアップロードします。
3. Settings → Pages → Deploy from a branch を選びます。
4. Branchを `main`、Folderを `/ (root)` にしてSaveします。
5. 数分後、表示されたURLを開きます。

## 安全設計
- 開始前にホラー演出であることを明示
- 常時使える緊急終了
- 個人情報入力なし
- 外部通信なし
- 実在企業・OSへのなりすましなし
- prefers-reduced-motion対応
